# Logo

File: `logo.png`. The prompt below was written by the codex CLI (`codex exec`).
Ahmed generates the image from it in ChatGPT and saves the result as
`assets/logo.png`, which the README header references.

Prompt:

Create an original minimalist logo for a personal Debian/Ubuntu desktop configuration project called Debian Linux Config, a large centred Debian-family counterpart to a geometric mountain-shaped symbol, constructed from three rounded tiled window panels with clear visible gaps and a tiny angular terminal prompt accent, using flat crisp shapes in Debian red #A80030 with a subtle warm coral highlight on a solid dark #1e1e2e background, preserve the visual language of the sibling Arch project with generous margins, strong geometric balance, clean edges, and clear readability at small README icon size, use only straight, angular, block-like, or sharply segmented accent forms, include no spiral, swirl, curl, comma, teardrop, loop, coil, ribbon, flowing curve, or any curved flowing shape anywhere in the mark, do not place decorative symbols inside the panels that could suggest a distribution emblem, keep the three-rounded-panel mountain arrangement unmistakable, include no text, no lettering, no watermark, and ensure the mark is entirely original and does not replicate, imitate, or closely resemble the official Debian swirl or any official distribution logo

The first version of this prompt asked only that the mark not resemble the Debian
swirl. The image it produced put a spiral in the top panel and a swirl-shaped
highlight in the left one, so this revision names every curved form it must avoid
and asks for angular accents instead. Keep the 512 px export the README uses: the
header renders at 240 px, and a 1254 px original cost five times the page weight.
